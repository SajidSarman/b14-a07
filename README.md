# Bazar Dor - B14-A07

It's a Bangla-language web app for checking current prices of everyday products. It brings product prices, market comparisons, and daily price changes together in one place.

## Live Link
https://bazar-dor-b14-a07-s-sarman.vercel.app/

## Technologies

- Next.js
- TypeScript
- Tailwind CSS
- HeroUI
- Better Auth with MongoDB
- React Hot Toast and React Icons

## Key Features

1. Browse current prices for everyday products.
2. See products with rising or falling prices.
3. Browse products by category.
4. View product details, including market-level prices and price summaries.
5. Create an account or sign in with email, Google, or GitHub, then update profile information.
